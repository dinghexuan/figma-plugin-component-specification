# 主题化配置器

本地 Figma 插件，按提供的需求文档、四个 Figma MCP 设计节点和桌面上的颜色算法实现。插件运行时完全离线，不上传设计稿或变量数据。

## 在 Figma 中使用

1. 打开 **Figma 桌面客户端**和需要配置的设计文件。
2. 选择 **Plugins → Development → Import plugin from manifest…**。
3. 选择本文件夹内的 [manifest.json](./manifest.json)。
4. 在开发插件列表中运行 **主题化配置器**。

已提供 [构建产物](./dist/)，首次使用无需安装 Node.js 或执行构建。已设置 Figma 分配的正式插件 ID `1691799069719255223`，开发和 Community 发布均使用此 ID；**不能删除 ID 或改回旧本地 ID**，因为 Figma 的私有文件配置 API 必须使用插件 ID。

如果此前导入的是旧本地 ID 版本，请关闭插件，重新执行 **Import plugin from manifest…** 并选择本文件夹的 [manifest.json](./manifest.json)，然后继续发布。更换 ID 后旧 ID 的私有文件配置不能直接读取，插件会重新读取已有变量而不重建它们；在已有文件中使用前，请核对基准值和手动覆盖配置。

更新本地插件后，关闭当前插件窗口，并从开发插件列表重新运行即可加载新构建，不需要重新创建变量或重新点击“生成”。

如果旧版曾在无 ID 的情况下导入，更新后请先关闭插件，重新执行 **Import plugin from manifest…** 并选择本文件夹的 [manifest.json](./manifest.json)，使 Figma 重新加载 ID，再运行插件。插件成功读取已有变量前输入框和“生成”按钮不可操作；初始化错误会持续显示，不会让界面看似修改成功却没有写回。

## 操作

- 默认进入颜色页；Light、Dark 分别保存基准色和手动覆盖值。
- 点击分组标题或箭头展开/收起；点击输入框聚焦并全选。
- HEX 支持带或不带 `#`、大小写、三位缩写。派生颜色还支持八位 HEX 透明度；基准色固定为不透明。
- 点击色块打开与设计稿对应的插件内颜色选择器，支持 HSB、HSL、RGB、HEX、透明度和取色。Light/Dark 中性色的基准色和派生色默认使用 HSL，其他色板默认使用 HSB；手动切换后，本次运行会分别记住各色板的格式选择。格式切换不会改变颜色或写入变量。当前宿主不支持屏幕取色时会明确提示。
- 选择器的 H/S/B、H/S/L、R/G/B 和可编辑的不透明度输入框支持 ↑/↓ 每次 1、Shift+↑/↓ 每次 10，连续按键保留焦点，数值限制在各通道有效范围内；Enter 提交，Escape 放弃未提交草稿。基准色不透明度仍固定为 100%。
- 色板仅在从区域内开始按下主指针后拖拽选色；鼠标松开（包括区域外）、取消拖拽、失去指针捕获、窗口失焦或关闭选择器都会结束拖拽。未按下鼠标的移动不会选色。
- 手动修改派生值后显示“重置”；重置按**当前**基准值重新计算。修改基准值不会抹掉其他手动覆盖。
- 数字输入支持 ↑/↓ 每次 1，Shift+↑/↓ 每次 10。字号基准值只接受 12–24 的偶数，因此经过奇数时会提示，并且不会写入变量。
- 图标尺寸默认跟随字号 +4。手动改图标基准值会平移整个图标尺寸梯度；点击其“重置”恢复字号联动。你确认的 `icon-size-xl` 算法是字号 +6。
- **组件尺寸**展开区域内提供额外的**间距**配置，包含 `size-unit`、`size-step` 和八个 padding token，不改变设计稿中的六个尺寸首屏卡片。
- 点击“生成”补齐所有 176 个变量，不只生成当前标签页。完整集合已存在时按钮禁用，后续修改自动实时同步。
- 只保留 Figma 自带的窗口标题栏，插件内容不再重复显示标题和关闭按钮。“取消”会先完成已排队的最后修改再关闭；若同步失败会保留窗口并明确报错，方便修正后重试。Figma 标题栏的关闭按钮由宿主管理，可能中断仍在进行的同步；需要确保最后修改已保存时请使用“取消”。关闭不会撤销已写入的修改。

## 变量结构

Figma 使用变量名称中的 `/` 表示分组。按需求截图创建小写 **light / dark 分组**，而不是两个收费计划相关的 Variable Modes；读取及写入集合的默认 mode，不改动已有其他 mode。识别已有变量时兼容 `Light/Dark` 等大小写写法，不重命名原变量；旧版插件保存的覆盖值也会自动迁移。

| 集合 | 变量名称 | 数量 |
| --- | --- | ---: |
| 梯度色板 | `light/color-primary/1…13`、`dark/color-primary/1…13`；同样包含 gray、success、error、warning | 130 |
| 文字 | `font-size/5xl…xs`；`font-weight/bold、semibold、medium、regular、light` | 14 |
| 尺寸 | `icon-size/2xl…xs`；`control-height/2xl…xs`；`border/width`；`size-unit`、`size-step`；`padding/2xl…3xs` | 23 |
| radius | `infinite、4xl、3xl、2xl、xl、lg、md、sm、xs` | 9 |

功能表中成功色误写的 `color-gray` 按详细命名规则使用 `color-success`，避免覆盖中性色。字重和圆角以算法表为准：包含 bold，圆角无限值使用 infinite，固定 999。圆角基准值为 0 时，sm 和 xs 按原公式产生负值，未擅自增加截断；只有 padding-3xs 使用文档规定的 `max(0, …)`。

## 双向同步和数据保护

- 未点击生成前不创建集合或变量；手动提前建立的完整或部分对应 token 会自动读取并实时更新，**不需要先点击生成**。其他色板、`gap`、`font-lineheight` 等非本插件管理的变量保持不变。
- 打开插件时读取对应的已有变量，保留已有手动值和透明度，不覆盖无关变量。
- 插件打开期间每 800ms 检查对应变量变化；在 Figma 变量管理中修改基准 token 会重新计算未被覆盖的派生 token，修改派生 token 会显示为可重置的覆盖值。
- 使用顺序消息队列和实际值比较避免反馈循环及重复写入；补齐变量时保留既有 ID。
- 输入先即时更新本地预览；同一帧内（16ms）的编辑合并发送，最多允许一个编辑批次正在等待宿主确认。宿主忙时，只合并同一控件连续、尚未发送的旧值；不同控件、覆盖和重置的顺序保持不变，宿主确认后立即同步剩余最新值，避免消息积压。
- 每个编辑批次仍先读取当前 Figma 值，保留外部修改、删除检查及 alias 行为，但只扫描一次、校验整个批次后再写入最终结果，并回传一次完整快照。仅写实际变化的变量；颜色梯度按模式/色板及其依赖缓存，修改尺寸不重新生成颜色，私有配置未变化时不重复保存。
- 每次扫描一次性建立变量索引，按集合和完整名称查找，不再为每个 token 反复遍历全部变量；未管理的变量不读取其值。只有标签页、模式或展开状态变化时重建界面，普通输入及宿主确认只更新现有控件，保留焦点、输入草稿和点击目标。
- 宿主消息按 Figma 的 `pluginMessage` 协议接收，兼容原生 WebView 以插件窗口自身或空来源投递的事件。初始化无回应超过 5 秒时会持续显示明确提示，不会无限静默禁用控件。
- 配置存储在当前 Figma 文件的插件数据中，关闭再打开可恢复。Dark 的混色前基准色也单独保存；首次导入无插件数据的 Dark 色板时，由第 9 阶反推基准色，并保留所有已有梯度的精确值。
- 同名集合、重名变量、类型不匹配、无效基准值、不可解析或循环引用会明确报错，不会静默创建重复集合。已有 alias 可读取，只有需要改变其实际值时才会写成具体值。
- Figma 写入权限或 API 失败会明确提示；如中途生成失败，可处理原因后再次生成，已有变量会复用。

## 平台限制

Figma 公共插件 API **不提供打开 Figma 自带颜色选择器的接口**。已按你确认的方案实现插件内高还原颜色选择器，而非声称调用不存在的 API。参考：[官方 Plugin API](https://developers.figma.com/docs/plugins/api/figma/)。

## 开发

安装 Node.js 20.19+ 后，在本文件夹执行：

```sh
npm install
npm run build
npm test
npm run preview
```

浏览器预览地址为 `http://127.0.0.1:4178/`。预览只模拟变量，不能写入 Figma；真实变量操作需导入插件后执行。

- [src/palette-algorithm.js](./src/palette-algorithm.js)：原样复制的用户颜色算法。
- [src/model.ts](./src/model.ts)：数值算法、覆盖和恢复逻辑。
- [src/sync.ts](./src/sync.ts)：Figma 变量同步。
- [src/main.ts](./src/main.ts)：插件宿主及消息队列。
- [src/ui.html](./src/ui.html)、[src/ui.css](./src/ui.css)、[src/ui.ts](./src/ui.ts)：界面和交互。
- [assets/](./assets/)：Figma MCP 原始 SVG；构建时嵌入 HTML，不依赖临时资源链接。
- [tests/plugin.test.mjs](./tests/plugin.test.mjs)：精确算法、边界、导入、持久化、alias、补齐和双向同步测试。

字体按设计稿使用本机已安装的 MiSans Medium、Demibold、Regular，缺少该字体的其他电脑会使用中文系统字体。未打包或上传本机字体。

构建包含 TypeScript 严格类型检查和 48 项自动化测试，包含构建产物、实际宿主入口消息队列及 UI iframe 与宿主之间的完整消息桥接验证。测试会模拟 Figma 私有配置对插件 ID 的要求和窗口自身、父窗口、空来源消息，验证无 ID 时明确阻断编辑、加载实际 manifest ID 后成功初始化、初始化超时错误持续可见并可在收到快照后恢复，以及构建拒绝缺少 ID 的 manifest。手动变量测试使用截图中的小写分组与已有覆盖值，覆盖不点击生成就修改颜色/字号、Figma 外部编辑回传 UI、大小写兼容、旧版配置迁移和原变量 ID 保留。另验证连续 20 次输入和宿主回传不会删除输入框/色块或丢失焦点、光标、未完成草稿，色块打开最新颜色，数字键盘调整和派生值重置可用，以及 2175 个变量的扫描保持线性原生属性读取量。选择器测试覆盖 HSB/HSL/RGB/透明度快捷键、连续按键与边界、中性色默认格式、HSL 颜色转换及低亮度精度、无效输入提示、HSL 编辑写回已有变量，以及松开/取消/失去捕获/失焦/关闭后停止选色。

性能回归使用实际构建的 UI/宿主消息桥和 2175 个变量，阻塞宿主读取时连续输入 21 次：优化前 21 次扫描、139 次变量写入、21 次配置保存和快照回传；优化后 2 次扫描、22 次变量写入、2 次保存和快照回传。另验证同一帧的 8 个混合编辑只扫描/保存/回传一次，边界快捷键不发送无效重复编辑，批次保留覆盖/重置顺序且无效批次在写入前报错，等待期间的外部覆盖保留，“取消”等待最后值，批次失败解除等待并恢复宿主状态以便重试。此测量是模拟宿主下的调用次数，不代表真实 Figma 耗时或帧率。

移除内部重复标题后，内容区为 400×580 颜色首屏、400×626 尺寸首屏、400×764 展开状态（以上均不包含 Figma 自带标题栏）；其他设计稿的卡片尺寸、输入框、间距和 256×344 颜色选择器保持不变。Figma 宿主写入通过 API mock 和真实 UI iframe 联动测试验证；仍需在真实 Figma 文件中完成开发插件验收。
